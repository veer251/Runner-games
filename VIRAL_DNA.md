## 3. THE VIRAL DNA (the patterns that repeat)

### 3.1 Skeleton
```
[0:00-0:08]  HOOK  – greet the viewer in a ROLE ("Hello!", "Welcome, Slayer", "Hey Zootopia citizens")
                     or a THREAT in their face (T-Rex roar). Big text, speed-lines, 1 silhouette.
[0:06-0:12]  LEVEL MAP – 3–8 illustrated level panels (+ difficulty names) = promise of variety → retention
[      ]     LEVEL CARD – "LEVEL N" + move silhouettes joined by "+" (new move gets a "NEW" badge)
[      ]     3-2-1 / GO
[LEVEL]      gameplay in ONE distinct world, 1 gimmick, cues every 2–3 s
[      ]     TRANSITION CARD – story line or praise ("ARE YOU READY?", "Lights out! Trust no one!",
             "Let's get stretching!", "YOU ARE AMAZING!", "TAKE A BREATH")
...repeat, each level = new world + new move/gimmick, harder...
[FINALE]     boss fight / final escape / "FINAL PUNCH" / "BREAK DOWN THE WALL"
[END]        celebration (IP characters) → "MISSION COMPLETED / CONGRATULATIONS"
             → CTA tied to the game ("PUNCH THAT SUBSCRIBE BUTTON", "comment which level next")
```

### 3.2 Timing rules
| Format | Total | Levels | Level length | Transition cards |
|---|---|---|---|---|
| **Short**, ImmerZone type (the highest views) | **3:20–4:50** | **3–4** | **35–60 s** | 4–8 s each |
| **Long**, Escapify / Jurassic type | **7–11 min** | **6–8** | 35 s → **grows to ~100 s** (Escapify) or ~60 s flat (Jurassic) | 5–10 s + 1–2 rest cards |

- **Something new must happen every 40–60 s**: a new world, a new move or a new gimmick. Never 2 minutes of the same.
- A new obstacle or cue every **2–3 s** (Escapify voice cadence).
- Intro (hello + map + card) ≤ **15–20 s**. Outro ≤ **15 s**.
- **A rest beat in long videos** at ~40% ("TAKE A BREATH", "BREATH", stretching level).

### 3.3 Level progression (difficulty curve)
1. **L1: tutorial world, bright daylight**, 2–3 basic moves (run, jump, dodge/duck).
2. **L2: contrast world, darker or enclosed** (tunnel, dormitory, airplane, duct), plus **1 gimmick**: pose walls ("Hole in the wall"), freeze (red light / green light), stretching.
3. **L3: spectacle world** (lava, concert, glass bridge, space), plus **1 NEW move** (slash, dig, punch, grab).
4. **L4 / finale: BOSS or ESCAPE**: health bar, rounds ("ROUND 2", "FINAL ROUND"), punch combos, "HIT!" pops, or a final breakout ("Escape this stage for freedom!").

**Consecutive levels always contrast in light and colour**:
- day → dark → fire
- pink cabin → daylight street → dark concert
- sand arena → red-dark dorm → black glass bridge → boxing ring

### 3.4 Gimmick library (what fills a level besides run/jump/duck)
| Gimmick | Seen in | What the viewer does |
|---|---|---|
| **Pose wall / Hole in the wall** (yellow wall with a black silhouette cut-out) | Subway, KPop, Prison, Tom&Jerry, Jurassic | Copy the pose (kick, yoga tree, star, lunge) as the wall passes |
| **Freeze (Red light / Green light)** | Squid | Run on green, freeze on red |
| **Tile choice (glass bridge)** | Squid | Jump left / centre / right |
| **Boss boxing** | Squid, Demon Slayer | Punch / duck / dodge in rounds; boss health bar |
| **Rhythm punch lanes** (Beat-Saber style note blocks + combo counter) | Demon Slayer | Punch left/right on the beat |
| **Mirror me** (3-2-1 then hold the pose) | Demon Slayer | Copy the silhouette |
| **Stretching level** | Prison (vent duct) | Slow stretches, "NICE" feedback |
| **Dig / climb / swim arm motions** | Prison | Themed arm movement |
| **Breakable wall** (punch ×N, "FINAL PUNCH") | Railroad, Tom&Jerry | Punch combos |
| **Coins / giant coin grab** | Subway | Reach up / jump |
| **Enemies running or reaching at you** | Prison guards, KPop demons, Tom&Jerry | Dodge / punch / slash |
| **Named power modes** ("MEGA PUNCH TIME", "COMBO RUSH", "ULTIMATE REFLEX") | Tom&Jerry | Burst of fast punches |

### 3.5 Obstacle vocabulary → move mapping
| Obstacle | Move |
|---|---|
| Trains, containers, crates, enemies in a lane | **Side-step dodge** |
| Barriers, cones, gaps, lava | **Jump** |
| Overhead signs, pipes, lasers, beams | **Duck / squat** |
| Wooden or glass walls, bosses, enemies | **Punch** |
| Pose walls | **Pose** |
| Coins high up | **Reach / jump** |

### 3.6 Screen language (UI grammar)
- **Cards**: black background + white or yellow **manga speed-line rays**, big bold italic white text, white outline silhouettes of the moves joined by "+".
- **In game** (the ONLY HUD):
  - a round move icon top-centre (JUMP/DUCK/RIGHT) ~1 s before the obstacle
  - a thin progress bar at the top
  - optional distance/score/level x/N in the corners
  - a boss health bar only in boss levels
- **Praise words** between levels: NICE, EXCELLENT, AWESOME, YOU ARE AMAZING, PHENOMENAL, PROUD OF YOU.
- **Countdowns**: 3-2-1 / 4-3-2-1 before starts and big sections.
- **Branding inside the world**: channel name and "SUBSCRIBE" as graffiti or billboards on walls.

### 3.7 Story patterns
- **Mission framing**: "ESCAPE", "RUN FROM THE T-REX", "RAILROAD ESCAPE", "ESCAPE THIS STAGE FOR FREEDOM".
- **A villain or chaser** behind or ahead (inspector, T-Rex, guards, demons, doll).
- The viewer is given a **role**: runner, slayer, citizen, surfer.
- **IP characters** appear as a rival running ahead, as enemies, in cameo cut-aways, and celebrating at the finish.
- The **finale matches the story climax**: concert showdown, boss, breakout, "break down the wall".

### 3.8 Audio patterns
| Style | Who | Note |
|---|---|---|
| **Original themed song with lyrics** (AI-generated) | ImmerZone (the highest views) | Lyrics mention the moves; a countdown is built into the song |
| **Coach voice cue every 2–3 s** plus praise | Escapify, Demon Slayer | "Jump. Dodge left. Punch. You are amazing." |
| Instrumental hype track + shouts ("Woo! Heat!") + section countdowns | Railroad, Rooftop, Jurassic | Cheapest to make |

**For us:** the user's voice-cue MP3s (jump/duck/left/right/hit/push/smash) + a hype track + praise lines + 3-2-1.

### 3.9 Visual truth
- Blocky (Squid 13M), plain concrete (Railroad 13M) and one-environment (Rooftop 11M) videos still went viral.
- **Graphics are the multiplier, not the base.** The base is: a famous IP or theme, level variety every 40–60 s, clear cues, gimmicks, and a finale.
- Premium visuals (ImmerZone, FLEM, Jurassic) push a video from ~10M to ~35M.

## 4. Our blueprint (apply to every new game)

### 4.1 SHORT flagship (≈3:30–4:30) — default
| # | Segment | Duration | Content |
|---|---|---|---|
| 0 | Hook | 5 s | Role greeting + silhouette wave ("HEY SLAYER!") or a threat in the face |
| 1 | Level map | 5 s | 3–4 illustrated panels with level names |
| 2 | L1 card → L1 | 5 s + 40 s | Bright world, RUN + JUMP + DUCK, coins |
| 3 | Transition | 5 s | Story line ("Lights out!") |
| 4 | L2 card → L2 | 5 s + 45 s | Dark/enclosed world + **pose walls** or freeze gimmick |
| 5 | Transition | 4 s | Praise ("EXCELLENT!") |
| 6 | L3 card → L3 | 5 s + 50 s | Spectacle world + **NEW move** (slash/punch/dig) |
| 7 | Finale | 45 s | **Boss rounds** (health bar, ROUND 2, FINAL ROUND) or breakout + FINAL PUNCH |
| 8 | Celebration | 8 s | IP characters celebrate, confetti, "MISSION COMPLETED" |
| 9 | CTA | 7 s | "PUNCH THAT SUBSCRIBE BUTTON" + "comment next level" |

### 4.2 LONG version (≈8–10 min)
- 6–8 levels; 35 s → 90 s growing.
- A new move every 1–2 levels.
- "TAKE A BREATH" rest at ~40%.
- A mid-video "COMBO RUSH" / mini-boss.
- A final boss.
- A "LEVEL N CLEAR!" map between levels.

### 4.3 Engine features we must build (in our Three.js games)
- [ ] **Timeline/level system** driven by `config.js` (seconds per level, world preset, allowed moves, gimmick)
- [ ] **Card overlay system**: speed-line background, bold text, silhouette icons with "+", "NEW" badge
- [ ] **Level map screen** (panels built from in-game snapshots of each level)
- [ ] **Move-cue icon** (round, top-centre) ~1 s before each obstacle, plus voice cue
- [ ] **Progress bar** (thin, top); optional level x/N
- [ ] **Pose walls** (yellow wall, black silhouette cut-out, a library of 12 poses)
- [ ] **Freeze gimmick** (green/red light, the world stops, a figure turns around)
- [ ] **Boss mode** (boss model ahead, health bar, rounds, punch note-lanes + combo counter, "HIT!" pops, FPP fists)
- [ ] **Praise/transition text** pool + countdowns
- [ ] **In-world branding** (channel name + SUBSCRIBE graffiti textures)
- [ ] **Celebration** (IP characters dancing, confetti) + "MISSION COMPLETED" + subscribe-punch CTA
- [ ] **Recording mode**: deterministic seed, fixed 60 fps timeline, auto-play (no input needed), so the video can be screen-recorded straight to 4K
